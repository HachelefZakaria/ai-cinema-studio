# Support

For general usage questions and reproducible bugs, use the repository's GitHub
Issues after checking existing reports.

When reporting a problem, include:

- AI Cinema Studio version.
- Operating system and Python version.
- The provider and model name, but never the API key.
- A short description of the steps to reproduce the issue.
- Sanitized error output when available.

Do not post API keys, billing identifiers, personal information, private
creative briefs, generated media, or unredacted logs.

Provider account access, quotas, model availability, and billing are managed by
each provider. A successful connection test does not guarantee that a provider
will accept a paid generation request.
